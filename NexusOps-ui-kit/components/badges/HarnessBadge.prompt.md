Marks which harness runs a session. Sits in session rows, terminal headers, graph nodes, and worker cards.

```jsx
<HarnessBadge harness="claude-code" />
<HarnessBadge harness="codex-cli" />
<HarnessBadge harness="codex-cloud" showLabel={false} />
```

Keep it near-neutral — pair it with the ExecutionProfileBadge to answer "which harness, on which account."
