# /tdd brief — scrollback_producer_tap_and_recovery_seam

## Feature
Wire the headless VT model into the survival path: (1) a **producer tap** feeding each live session's PTY byte stream into a per-session `HeadlessVt`; (2) a **`ScrollbackStore` seam** (a daemon-internal trait + a `FakeScrollbackStore`) connecting producer → recovery; (3) the **recovery consumer** — `enumerate_recoverable_sessions` reads the store and populates `has_scrollback`/`replayed_event_count` so `decide_resume`→**`Replayed`** becomes reachable. The durable §15-gated store behind the seam is **075d** (this slice uses the Fake). Daemon-internal; NO contract.

> **Widens phase scope because** the VT arc's survival-wiring tail (075c) reaches Phase-4's §8/§8.1/§17 recovery ladder (the `Replayed` rung) while the producer/model stays Phase-3 terminal — the arc legitimately bridges 3.4→Phase 4 (the Phase-4 acceptance line "scrollback fidelity … with FakePty/recorded corpus" is what 075b/c close).

## Acceptance criteria (what "done" means)
- [ ] `ScrollbackStore` trait (daemon-internal, in `terminal/`): `save(&SessionId, &VtSnapshot)` + `load(&SessionId) -> Option<VtSnapshot>` + a `FakeScrollbackStore` (in-memory) for tests.
- [ ] **Producer tap:** a live session's PTY bytes feed a per-session `HeadlessVt` (the `screen_contents()` reflects the stream); a save trigger calls `ScrollbackStore::save` with the current snapshot.
- [ ] **Recovery consumer:** `enumerate_recoverable_sessions` takes a `&dyn ScrollbackStore`; for each session it `load`s the snapshot and sets `has_scrollback`/`replayed_event_count` from it (replacing the hardcoded `false`/`0`).
- [ ] With a populated store, the recovered session lands on the **`Replayed`** rung (`decide_resume`); with an empty store it falls through to **`Relaunched`** (today's behavior preserved).
- [ ] **The alt-active mapping (the 075b design-input):** a mid-alt-screen snapshot (`scrollback_len()==0` but restorable content) still yields `has_scrollback=true` → `Replayed` (it has a re-renderable screen) — keyed on `snapshot.has_restorable_content()`, NOT raw `scrollback_len()>0`.
- [ ] **Cat-1 boundary preserved:** the `session/` import-grep still passes (the `ScrollbackStore` trait is from `terminal/`, not `runtime/`/`eventstore/`/`gateway`); the producer holds `Box<dyn ScrollbackStore>`, never a `WriteHandle`.
- [ ] `supports_resume`/`has_resume_handle` stay `false` (the resume-handle/live-broker axis is 4.1b-2/HITL — 075c owns ONLY the scrollback axis).
- [ ] All tests pass; `/preflight` clean.

## Wiring / entry point (Step 7.5)
**Recovery consumer:** reachable from `run_restart_recovery` (`main.rs`, post-supervisor) → `enumerate_recoverable_sessions(&conn, &store)` → `decide_resume`. **Producer tap:** reachable from the `SessionActor` drive-loop (the live read-pump). In 075c the injected production store is a **placeholder/no-op** (the durable §15 store is 075d) — so production behavior is unchanged (empty store → `Relaunched`, as today); the `FakeScrollbackStore` tests prove the full producer→store→`Replayed` path. 075d swaps the real store behind the seam → `Replayed`-after-restart goes live (the 4.0a/043 "mechanism wired test-first, real impl next slice" precedent).

## RED test outline (Step 2)
1. **`test_scrollback_store_fake_round_trip`** — `save(sid, snap)` then `load(sid)==Some(snap)`; `load(unknown)==None`. Why: the seam contract.
2. **`test_recovery_populated_store_replays`** — pre-populate the Fake with a scrollback-bearing snapshot for a recoverable session → `has_scrollback=true`, `replayed_event_count==scrollback_len`, `decide_resume`→`Replayed`. Why: §8/§17 + LESSONS §36.
3. **`test_recovery_empty_store_relaunches`** — empty store → `has_scrollback=false` → `Relaunched` (today's behavior preserved). Why: no-regression (the default `Relaunched` rung, LESSONS §38).
4. **`test_recovery_alt_active_snapshot_replays`** — an alt-active snapshot (`scrollback_len()==0`, restorable alt content) → `has_scrollback=true` → `Replayed`. Why: the 075b alt-active design-input — the `Replayed` signal is "has restorable content," not raw scrollback (§0.1 re-render).
5. **`test_producer_tap_feeds_vt`** — drive the `SessionActor`/read-pump with FakePty bytes → the per-session `HeadlessVt.screen_contents()` reflects them. Why: the producer tap (§6.4/§9).
6. **`test_producer_saves_snapshot`** — the save trigger calls `ScrollbackStore::save` with the live snapshot (the Fake receives it). Why: the producer→store wiring.
7. **`test_session_cat1_boundary_holds`** — extend the `session/` import-grep: still no `crate::runtime`/`eventstore`/`gateway`; the producer holds `Box<dyn ScrollbackStore>`, not a `WriteHandle`. Why: the cat-1 boundary (LESSONS §28/§35).

## Things to flag at Step 2.5
1. **The `has_scrollback` mapping (load-bearing — the 075b design-input).** Map the `ResumeInputs.has_scrollback` from `snapshot.has_restorable_content()` (scrollback rows OR non-empty alt/visible screen) so a mid-alt-screen session re-renders, vs raw `scrollback_len()>0` (which drops alt-active sessions to `Relaunched`). My default: **`has_restorable_content()`** + flag the field-rename question (broadened meaning). `replayed_event_count` = `scrollback_len()` (honest 0 for alt-active). Vote: has_restorable_content + surface the rename.
2. **VT model placement / tap location.** (a) `SessionActor` owns the `HeadlessVt` + feeds it from `TerminalEmit::Output` bytes in the pump loop (keeps `TerminalSession` a pure byte-pipe; the survival concern lives in the session layer); (b) `TerminalSession` owns it + feeds in `read_step`. My default: **(a) SessionActor-owns** (the actor already drives the pump + the telemetry tick; `HeadlessVt` is pure/display-only → cat-1-safe in `session/`). Vote: (a).
3. **Save cadence/trigger.** When does the producer persist a snapshot? (i) the `SessionActor` status-poll tick (periodic — a crash leaves a recent snapshot, mirrors the 4.0c telemetry pump); (ii) on reap/clean-shutdown; (iii) both. My default: **(iii) both** — periodic for crash-survival + a final save on reap. For 075c (Fake), prove the tick-save is called. Vote: both (tick + reap).
4. **`ScrollbackStore` trait location + injection.** `terminal/scrollback_store.rs` (neutral, session/-importable; the durable 075d impl injected via `Box<dyn>`, LESSONS §35) vs elsewhere. My default: **`terminal/`** + inject (preserves the `session/` cat-1 import-grep — the trait is from `terminal/`, not `runtime/`). Vote: terminal/ + inject.
