## Decisions made

- **3.3c B2 (the harness discriminator) over B1 (handler untouched).** The daemon classifier is Claude-hardcoded; Codex MCP is `Guaranteed`→Adjudicate (vs Claude's BestEffort→deny) and `apply_patch` isn't a Claude tool — so "handler untouched" can't faithfully route Codex (the brief's own test required `mcp__*`→`agent.mcp_tool`). Lead-ruled **B2** (away-log Decision 18). The Gateway loop is reused literally unchanged; only the parser/classifier diverges (LESSON §42). Security CLEAR (0/0/0/0).
- **PIN-1 (the by-construction crux):** the `harness` tag is stamped by the trusted hook binary (`--harness codex`), never read from agent stdin (`CodexHookPayload` has no such field) — a spoof can only ever select a MORE-conservative classifier, never a silent allow.
- **3.3c sandbox containment** (USER-CONFIRMED): `workspace-write` + `network_access=false` + `writable_roots={worktree + per-profile approved}`; read-scope NOT asserted (workspace-write reads all; only WRITES scope — INV-SEC-1 governs mutation).
- **3.3d Q1 = HOIST** the neutral primitives to `harness::telemetry` with re-exports (Claude byte-identical) over a Codex→Claude import.
- **3.3d cost honesty (Q3):** any locally-derived cost caps `metric_quality` at `Estimated` (the Claude-Exact vs Codex-Estimated divergence). **Only `Exact` is capped** — `Unavailable` (no context, the weakest axis) stands even with a derived cost (test-pinned).
- **3.3d pricing (Q2, orchestrator-decided):** ship INDICATIVE rates + a refresh-TODO (do NOT pull live pricing — NON-safety, `Estimated` already flags it); unknown/absent model → 0.0 (never fabricated).
- **CONTRACT: NO bump** both slices (the `harness` field, the pricing fn, the adapter fields, the hoisted module are all daemon-internal; `TelemetrySample`/`TelemetrySampled` frozen @0.20.0; the §6.3 `agent.*` catalog + `intercept` RPC frozen).
