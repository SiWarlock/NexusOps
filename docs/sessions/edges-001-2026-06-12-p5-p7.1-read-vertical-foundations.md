## Decisions made (with rationale)

- **Two Findings raised + resolved** (brief-vs-spec precedence contradictions):
  - **edges-002:** brief Q1 default put `ahead/behind > dirty`, contradicting the LOCKED §5.1-R7 (`ARCHITECTURE.md:53`: `locked/conflicts > dirty > ahead/behind > clean`). Honored §5.1; orchestrator corrected the brief. Final order recorded for the arch note.
  - **edges-004:** brief Q1 flat order put `ChecksPending` above the review states, contradicting its own test 9 (`Approved`+pending → `Approved`). Reconciled: `ChecksFailing` HARD (above review), `ChecksPending` SOFT (below review) — a match-cascade, not a flat rank (Mergeable/Approved are conditional on review=Approved). Orchestrator confirmed + corrected the brief.
- **`as_wire_str` hand-mapped + serde-parity-pinned** (edges-002) — `&'static str` ergonomics + zero drift risk (a test asserts equality with the frozen serde wire value for every `ALL` variant; an exhaustive match forces a reconcile if `shared/` adds a variant). LESSON §2.
- **`RetryAfter::Until(Timestamp)`** (edges-003) — RFC3339-Z, daemon-idiomatic (lexical-compare-ready per LESSON §5); pure (no Clock). HTTP-date parsed via the existing `time` dep (IMF-fixdate runtime `format_description`), no new dep.
- **`Vec` empty-degraded + `Option<Timestamp>`** (edges-005) — a diff/log is naturally a possibly-empty list (vs `read_worktree_status`'s `Option`); `from_unix_timestamp` is fallible → `Option` keeps the read no-unwrap. A review-caught HIGH was fixed: `DiffOptions::show_untracked_content(true)` (untracked line counts were silently 0) + `diff_tree_to_workdir_with_index` ("git diff HEAD" semantics, catches staged changes).
- **Review-agg `None` fallback** (edges-006) — `ReviewRequired` is branch-protection state not derivable from `reviews[]` alone; the MVP fallback is `None`, and the octocrab client layers in `reviewDecision → ReviewRequired` later.
- **Reviewer policy applied correctly:** security-reviewer ran on the git2/forbidden-#6 + §17/auth slices (001/002/003/005 — all CLEAN); SKIPPED on the pure-derivation slices (004/006 — no mutation/secrets/git2/auth) per the `invariant` policy (orchestrator-confirmed).
