## Decisions made

- **Q1 EmittedEvent bridge = B (generic `Namespaced`)** — one gateway/ edit serves all ~11 edges events vs 11 typed
  variants (lowest cross-track contention); `SessionStarted` stays typed (genuine envelope override). The
  `object_ref` field was simplified OUT (AppendIntent has no generic slot; identity rides the action envelope +
  the payload's own ids, LESSON §10/§17).
- **§15 strip-at-source** = authority-scoped, last-`@`-in-authority delimiter, ALL scheme-URL userinfo stripped (a
  token can ride the bare-username slot); scp-style ssh intact; Redactor is the backstop only.
- **git mutations via the injected `GitCli` seam** (forbidden #6); `WorktreeId::new()` direct (the
  `ExecutionProfileId::new()` domain-id precedent; persisted-once + rebuild-reads-it → replay-safe), NOT IdGen.
- **Arg-injection guard** = reject leading-`-` operands fail-closed (a SHARED `reject_dash_operands` across both
  git arms); `repo_path` exempt (it's the cwd via `current_dir`, not a git arg).
- **proj_worktree status via `wire_value(&WorktreeOverlay::Creating)`**, NOT `DerivedWorktreeStatus::as_wire_str()`
  — **a layer-direction correction** (the orch's Step-2.5 approval missed it): `DerivedWorktreeStatus` is in the
  `git/` EDGE, `projections` is persistence-core → importing it reverses the layer direction. Same serde-pinned
  "creating" output, layer-compliant.
- **proj_worktree failure taxonomy:** identity-less (no project_id / no action_request_id / no Repo ref) → healthy
  skip; missing durable sibling row → fail-closed Db (LESSON 17); unbindable data → Decode/degrade.
